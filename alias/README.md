# orazaka

The short name of [`@krizaka/orazaka-cli`](https://www.npmjs.com/package/@krizaka/orazaka-cli), the CLI of
[Orazaka](https://www.krizaka.com/en/products/orazaka) — the sovereign AI platform by [Krizaka](https://www.krizaka.com).

```bash
npx orazaka install   # clones the platform into ./orazaka and configures it
npx orazaka start     # Docker infrastructure
npx orazaka dev       # the whole stack
```

`npx orazaka …` and `npx @krizaka/orazaka-cli …` run the same CLI: this package only depends on the exact version of
`@krizaka/orazaka-cli` and starts it. Documentation, issues and source:
[krizaka/orazaka-cli](https://github.com/krizaka/orazaka-cli).
